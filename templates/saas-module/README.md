# SaaS.Example

This is a module boundary, not generated business behavior. Add the project to the chosen product host only. Platform and shared themes must never reference this module.

Before adding persistence, assign one schema/history/context migration owner and record consumed/provided interfaces and negative tests in a task plan. Resolve customer connections only through the validated routed-shell abstraction. Use the shared transaction/audit contracts, fresh authorization, resource rules and idempotency contracts before exposing writes. Never add runtime EnsureCreated, migrations, seed repair or database drops.

Generated under src/Modules, the default SaasPlatformRoot resolves src/Platform. Outside that layout pass an explicit MSBuild SaasPlatformRoot. Inherit the repository's central SDK/packages/build settings. This template has no data model or migration stream, no endpoint and no implicit permission grant.
